第二章:
 
此章完全可以跳过了.现在不认识Form的用法的人还有多少呢?起码我是搞明白好久了.详实的资料在http://www.w3schools.com 可以查询到
 
要点:
 
1.POST, GET是Form向CGI传送信息的路径.是通过把数据流(stream)利用环境变量来向CGI输送的.
 
2.这个数据流的格式为 每个变量信息间通过&符号来分割,变量通过=符号来说明他的值.最后一个变量用回车号<CR>来结束.如同这样:
BuildYourOwn&task=Calculate%20/*这个是空格*/Order&foosball=grayArcade&offense=redDynamos….<CR>/*回车*/
 
3.c++里头怎么储存这个通过POST/GET得到的数据流?是通过struct结构.如同这样:
typedef struct CustomFormStruct /*通过typedef把struct抽象化成一个数据型*/
{
    string functionToPerform;
    string taskSelected;
    string foosballTable;
    …
}
