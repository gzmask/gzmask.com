For some reason, I start to ask myself this stupid question after I turned 30:

Am I too old to start doing X? (X can be anything, Master Degree, Guitar, etc.)

After some logical thinking, the sane anwer is:

I will never be too old to start doing X.

It will only be an older version of me without X if I don’t start to do it soon enough.

So be a man, live hardcore, stop the whining.
